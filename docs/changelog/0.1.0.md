# windows-gadgets v0.1.0

Date: 2026-11-13

Windows 日常使用的四个小工具首次发布.

## Highlights

- `imeswitch` 按前台窗口自动切换中英文输入法, 并接管 Esc 与单独按下的左右 Alt.
- `pathclip` 自动把剪贴板里的 Windows 路径转换成可配置的格式.
- `wslproxy` 支持 Windows 到 WSL 的正向转发, 以及 WSL 回环到 Windows 的反向转发.
- `fncaps` 把 CapsLock 扩展成一组可配置的高频快捷键.

## Features

- `imeswitch`: 前台窗口变化时切回英文输入法, 中文布局下自动保持中文模式.
- `imeswitch`: 单独按左 Alt 切英文, 单独按右 Alt 切中文. Alt 组合键, Alt 加鼠标按键或滚轮, 以及全屏应用都保持系统原有行为.
- `imeswitch`: 自动把 CapsLock 恢复为非大写状态, 可用 `--no-ensure-lowercase-state` 关闭.
- `pathclip`: 盘符路径转正斜杠, UNC, `//` 与 `\\?\` 路径保持原样, 支持 WSL 路径, file URI 与正则转换链.
- `pathclip`: 自动模式不改写资源管理器复制的文件对象, 只有按下 profile 热键时才转成路径文本.
- `wslproxy`: 按 TOML 规则维护正向与反向转发, WSL 地址变化后自动重新解析目标.
- `wslproxy`: 内嵌 Linux helper, 不需要在 WSL 里单独安装组件.
- `fncaps`: 首次运行自动创建配置, 支持用系统默认程序打开配置.
